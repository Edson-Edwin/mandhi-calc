# Code of Conduct

Everyone participating in this project should be treated with respect, regardless of background, identity, or experience.

## Expected behavior

- Be welcoming and patient, especially with new contributors.
- Discuss ideas and code constructively; avoid personal attacks.
- Respect differing opinions and accept feedback in good faith.
- Respect privacy and do not share personal information without consent.

Harassment, discriminatory language, threats, sexualized conduct, doxxing, spam, and repeated disruptive behavior are not acceptable.

## Scope and moderation

These expectations apply to project issues, pull requests, discussions, and other project spaces. The maintainer may edit or remove inappropriate content, close disruptive threads, or restrict participation. Responses should consider the context and severity of the behavior.

## Reporting

For public conduct concerns that contain no sensitive details, contact [@Edson-Edwin](https://github.com/Edson-Edwin) in the relevant GitHub thread. If a concern includes private or sensitive information, use GitHub's **Report content** or **Report abuse** controls rather than posting those details publicly. See [GitHub's reporting guide](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).
