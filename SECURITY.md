# Security policy

## Supported code

Security fixes are currently maintained on the `main` branch. Older snapshots do not have a separate support commitment.

## Reporting a vulnerability

Please use the repository's [private vulnerability reporting form](https://github.com/Edson-Edwin/mandhi-calc/security/advisories/new). Do not disclose exploit details or personal data in public issues or pull requests.

Include the affected commit, reproduction steps, expected and actual behavior, and potential impact. Use synthetic data, and omit credentials or private bills. There is no guaranteed response deadline or bug bounty.

## Data handling

This is a browser-based static application. Plans and optional names are stored in browser local storage. The app does not have an application backend or analytics. Google Fonts is an external resource, and clipboard access is used when copying a summary.

Calculation errors without a security impact can be reported through the normal bug issue form.
